Docker import & export:		Done
How the following command works:
docker run -it ubuntu /bin/bash

here -it will forward the docker terminal to ubuntu bash.
then type ls command.

then mkdir demo then ls command.

Flow: Use base image->Create container for it->you will work in it-> You can share your credit work with your teammates.

If you want that the container will run in background then press ctrl+p+q.
Then show the running container using:
docker container list

export the container:
docker export container_id > myUbuntu.zip

then ls

Import the container:
docker import - myub < myUbuntu.zip

Show images list:
docker images
 
Run the imported image:
docker run -it myub /bin/bash

then ls

Now the created folders inside the imported image will show.

Command line options: Open Port(Docker run port option):
docker run hacstac/react-example

Exit from running  by react example  via pressing ctrl+c

Explain the following:
docker run -p 80:80 image-name

Now:
docker run -p 8080:80 hacstac/react-example

docker run -p <HOST_PORT>:<CONTAINER_PORT> <image>
Click on open port then enter 8080, react app will appear.
--------------------------------------------------------------
Command line options - Memory:
docker run -p 8080:80 -m 6M hacstac/react-example (This is not required memory to run react application, and will create the problem).
Run the command with different memory option:
docker run -p 8080:80 -m 6000M hacstac/react-example (This time the react application will run).
--------------------------------------------------------------
Command line options - Detach:
Explain the following command:
docker run -d image-name

The following command will run the react application in background on terminal so that you can use the terminal for other purpose.
